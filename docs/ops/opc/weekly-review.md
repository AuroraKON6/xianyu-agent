> This file is the template for the weekly one-person company dashboard review.
> It identifies bottlenecks and sets one clear priority for the next cycle.

## Review Cadence

### Daily (5 minutes)

- Check new inquiries and pending reply drafts.
- Check WorkOrders and failed execution jobs.
- Record any useful observations (title pattern, reply that worked, supplier note).

### Weekly (30 minutes)

- Fill out the template above.
- Identify the single biggest bottleneck.
- Set one priority for next week.
- Archive weak experiments; preserve reusable assets.

**Mindset guidance**: "专注做好我们能控制的事情，不能控制的交给天意." Focus on what's controllable: selection quality, title optimization, image quality, copywriting, reply speed, and reply quality. Don't obsess over exposure numbers or platform algorithm changes — those are uncontrollable.

### Monthly (1 hour)

- Review category performance trends.
- Decide: continue testing, scale, pause, or kill each category.
- Identify repeatable category playbooks.
- Identify products suitable for ecommerce scaling.
- Plan next month's discovery focus.
- Consider: is it time to move from杂货 testing to vertical store operation?

---

## Decision Framework

| Situation | Decision |
| --- | --- |
| Product getting inquiries but no orders | Fix reply strategy or pricing. Give it 1 more week. |
| Product getting orders but high after-sales | Pause. Investigate supplier quality. |
| Category getting no traction after 2 weeks of testing | Kill. Move resources to better category. |
| Category getting consistent orders | Scale. Add more listing variants. Negotiate better supplier pricing. |
| Reply template working across multiple products | Save as reusable asset. Apply to similar products. |
| Supplier consistently causing issues | Drop supplier. Find alternative. |
