# Xianyu Listing Playbook

> This file defines how to generate structured, approval-ready listing drafts for Xianyu.
> It guides the listing agent's output format and quality standards.

---

## Listing Principles

1. **Non-standard products compete on detail.** Title, image, specification clarity, and trust signals determine conversion — not just price.
2. **Differentiation prevents penalties.** Same product across multiple links must have different titles, images, and copy. Platform penalizes duplicates.
3. **Low-price entry attracts clicks.** Use a lower-priced variant or specification as the visible price, with full-price options in the description.
4. **Trust beats hype.** Buyers want specification clarity, honest descriptions, and responsive communication — not夸张 claims.

---

## Listing Draft Structure

Every listing draft produced by the listing agent must include ALL of the following fields:

### 1. Main Title

- **Length**: 30 characters max.
- **Format**: [Core keyword] + [Differentiator] + [Key specification or use case].
- **Rules**:
  - Must contain the primary product keyword for search discoverability.
  - Must differentiate from competitor listings (material, size, use case, or quality signal).
  - Must NOT be copied from other sellers.
  - Must NOT contain misleading claims.

**Example**: `商用不锈钢操作台 带制冷 冷藏工作台 餐饮厨房设备`

### 2. Search Keywords (5-10 terms)

- Include the product name, material, use case, and buyer search terms.
- Include both specific and broad terms.
- Example for a commercial work table: `操作台, 不锈钢操作台, 商用操作台, 冷藏操作台, 厨房工作台, 餐饮设备, 制冷工作台, 不锈钢工作台`

### 3. Lead Image Requirement

- **Must be**: Square format, high resolution, real product photo.
- **Must show**: The product in a场景 (application context), not just the product alone.
- **Must NOT be**: Copied from other sellers, stock photos, or misleading images.
- **Differentiation**: Can add text overlay highlighting key feature (e.g., "304不锈钢", "承重200斤").
- **If owner has product**: Use real photos from multiple angles.
- **If owner doesn't have product**: Generate image requirements for the operator to source (supplier photos with permission, or own photos of样品).

**首图 best practices** (from operational experience):
1. 正方形高清实拍图 — square, high-res, real photo.
2. 完整展示产品 — show the whole product, not a局部图 (partial view). Application场景 shots (product in use) are even better.
3. 差异化文字 — add text overlay to differentiate from competitors (e.g., "304不锈钢", "厂家直供").
4. 厂家感 — if positioning as a manufacturer, product堆积图 (bulk/stacked photos) build credibility.

**Why首图 matters**: In the Xianyu search results, buyers see the image first. A good首图 = more clicks = more "我想要" = more inquiries. "好的首图不但可以提高曝光，点'我想要'的人数也会不断增加!"

### 4. Specification Table

Present product variants clearly:

| Specification | Size | Material | Feature | Price |
| --- | --- | --- | --- | --- |
| 基础款 | 120×60×80cm | 201不锈钢 | 常温 | ¥680 |
| 升级款 | 150×70×80cm | 304不锈钢 | 常温 | ¥880 |
| 制冷款 | 120×60×80cm | 304不锈钢 | 风冷 | ¥1,680 |

### 5. Price Ladder

- **Low entry price**: Show the lowest-priced variant as the listing price.
- **Clear upgrade path**: Higher-priced variants shown in specification table.
- **Anchoring**: The highest-priced variant makes mid-range look like good value.
- **Low-entry explanation**: If using a cheaper variant as the visible price, explain in the description: "标价为基础款价格，具体规格价格请咨询。"

### 6. Trust Paragraph

Address buyer concerns proactively:
- Quality assurance: material grade, load capacity, durability.
- Shipping: how it ships, estimated delivery time, shipping cost.
- After-sales: return policy, warranty, support.
- Authenticity: factory direct, not resold from other platforms.

**Example**:
> 我们是工厂直供，所有产品均为实物拍摄。不锈钢材质，承重强，耐腐蚀。大件物品物流发货，全国大部分地区3-5天到货。如有质量问题，支持退换。下单前请确认规格尺寸，如有疑问随时咨询。

### 7. Delivery and After-Sales Notes

- Shipping method (courier vs. logistics for large items).
- Estimated delivery time.
- Return/exchange policy.
- What to do if item arrives damaged.

### 8. Operator Verification Questions

Before the listing goes live, the operator must verify:
- [ ] Supplier pricing confirmed (current and accurate).
- [ ] Product images are owned or authorized (not copied).
- [ ] Specification table matches supplier's actual offering.
- [ ] Shipping cost and method confirmed with supplier.
- [ ] No compliance issues (prohibited items, misleading claims, platform-sensitive content).

## Low-Price Entry Strategies

Low-price entry (低价引流) is about competing for traffic with competitors. The buyer sees a low price in the search results, clicks in, and then you guide them to the right (often higher-margin) specification. **Key boundary**: the description must always clarify what the listed price covers. If the platform flags it as恶意低价引流, the listing will be deleted.

**Recommended low-price range**: 50% of the actual product price. Too low = buyer skepticism. Too high = no traffic advantage.

### Strategy 1: Similar Product Combination

Use a lower-cost variant as the visible price. Example: list "常温操作台" at 680 yuan when the main product is "制冷操作台" at 1,680 yuan. Description must clearly state what the listed price covers.

**How**: Find a related but cheaper product from the same supplier. List it as the entry point. In the description: "标价为常温款价格，制冷款请咨询。"

### Strategy 2: Fictional Size Variant

Create a smaller size option at a lower price point. Description must clearly state the size and note it may be out of stock.

**How**: If the smallest real variant is 120cm at 680 yuan, create a "90cm" variant at 380 yuan in the description. Add "90cm款暂时缺货，可预订" to manage expectations.

### Strategy 3: Title-Image Price Misdirection

Show the premium product in the image with a title that includes both the premium and basic variant. The visible price is the basic variant. Must be done honestly — description must clarify.

**How**: Use the premium product photo as the首图. Title: "商用饮料柜 双门 单门 冷藏柜". The visible price is the single-door price. Description clarifies: "标价为单门价格，双门价格请咨询."

**Warning**: "切记价格不要太低，容易引起买家反感" — don't go too low, it backfires unless you have the conversion skills to turn it around.

**Boundary**: Low-price entry must not be deceptive. The description must always clarify what the listed price covers. If the platform flags it as恶意低价引流, the listing will be deleted.

## Listing City Selection

City selection affects trust, relevance, and shipping perception.

| Scenario | Strategy | Example |
| --- | --- | --- |
| Product has local demand | List in the demand city. | 平冷操作台 in 成都 (major餐饮 market). |
| Supplier ships from specific region | List in nearby first/second-tier cities. | Supplier in 河北廊坊 → list in 北京/天津/石家庄. |
| Buyer might want to self-pick-up | List in a city near the supplier warehouse. | Creates trust: "总仓在那边" is plausible. |
| Testing new category | List in your home city for easier logistics management. | |

**Why city matters**:
- Local buyers trust nearby sellers. "毕竟都是挨着的城市，就说总仓在那边也合情合理."
- If supplier ships from Hebei and you list in Guangdong, local buyers may lose interest.
- Platform may boost local relevance for certain categories.
- Self-pickup possibility adds urgency and trust.

## Agent Integration

The listing agent should:
1. Accept a product candidate (from discovery or manual input).
2. Generate a complete listing draft with ALL 8 fields above.
3. Flag items that need operator verification.
4. NOT auto-publish. Draft enters WorkOrder → Approval.
5. NOT copy images or text from other sellers.
6. Generate original copy based on product specifications and buyer value proposition.
