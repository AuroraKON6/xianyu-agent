## 交付（`integrations/mcp/server.py`）

**McpToolRegistry**——工具白名单注册表：
- 只接受 `read` / `analyze` / `propose` 三族（构造时拒绝任何其他 family——**没有 shell、没有任意 SQL、没有文件写**）
- `freeze()` 后注册表关闭：运行时不可新增工具
- 每次调用前 scope 检查（R03 principal；scope 不足 → `scope_forbidden` 403，**handler 不执行**）
- schema 锁（R19 模式）：调用方可钉死 digest；注册 digest 变化 → `schema_drift_stopped` 409
- 工具失败 → 结构化 `tool_failed`（处理函数按合同只读/只追加——失败不污染业务状态）

**build_default_registry**——标准工具面（与 HTTP API **派发到同一应用服务**，结果一致性由构造保证）：

| 工具 | 族 | scope | 说明 |
|---|---|---|---|
| `read__workflow_run` | read | commerce:read | 读 run 状态（账号作用域） |
| `read__capabilities` | read | research:read | 能力注册表 |
| `read__opportunities` | read | research:read | 候选清单 |
| `read__candidate` | read | research:read | 候选详情（**账号作用域在工具层强制**——与 HTTP 路由同检查） |
| `analyze__gate_inspection` | analyze | research:read | ready-gate 只读报告 |
| `analyze__candidate_export` | analyze | research:read | 候选导出行 |
| `propose__workflow_run` | propose | research:write+workflow:trigger | 建议一个 run（幂等键；**只提议不推进**——审批/执行留在人工 HTTP 面） |
