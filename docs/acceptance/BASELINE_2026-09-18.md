## 4. 调度器 / 注册器 / Pi 性质区分

- `agent_scheduler.start_agent_scheduler` 实际启动 4 个进程内异步循环：`discovery_loop`、`github_scan_loop`、`analytics_daily_loop`、`order_check_loop`。
- `discovery_loop` 仅调用 `agent.list_tasks()` 并打日志——确认计划判断：不是可靠可恢复的发现执行器。
- `listing_polish_loop` 定义仍在文件中但**未列入启动循环**，与「擦亮调度已退役」一致。
- `AgentRegistry.dispatch`（agent_registry.py:104）是同步 handler 分发 + 内存历史；无持久任务、租约或并发 worker。持久任务需 WP07，不在本轮声称。
- Pi（pi_runtime.py）为单 RPC 子进程串行回合 + 12 个 Typed Tools allowlist；本轮未启动，不作运行时声明。
